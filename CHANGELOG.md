# Changelog

## 0.1.0 — UI layer

First complete UI pass, wired to mock data. No real detection model or database yet.

- Design system: colour, spacing, radius, type and motion tokens; light and dark themes.
- Android: onboarding, home, live scan, zoomed specimen, capture review, image editor, identification mode, analysis, report, trait sheet, calibration, measure, dichotomous key, batch, history, reference gallery, PDF export, settings, phone pairing.
- Windows: workspace with inspector, import, live view from phone, compare, batch data grid, master-detail history and gallery, full report.
- Hidden screen gallery and component sheet.
- Tests for the box flow, back navigation, keyboard shortcuts, italic genus names and text scaling; screenshots of every screen and state.
